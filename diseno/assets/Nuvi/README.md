Nuvi, la mascota 3D de núvara: la personificación de un contador público. Los archivos salen de `apps/web/public/nuvi/` y de Drive › Marketing › Branding › Personaje.

| Archivo | Momento |
|---|---|
| `saludo.webm` | Intro de un tutorial |
| `pensando.webm`, `analizando.webm` | Mientras la plataforma procesa |
| `conexion.webm`, `dian.webm` | Conectar el token de la DIAN o una integración |
| `nuvi-onboarding.png` | Bienvenida y onboarding |
| `nuvi-senala.png` | Señala un dato o un botón: guía dentro de tutoriales y piezas educativas |
| `nuvi-procesos.png` | Con íconos de proceso conectados (documento, configuración, gráfico, organigrama, carpeta): explicar cómo la plataforma organiza la información |
| `nuvi-celebrating.png` | Hito: primera causación, configuración completa |
| `nuvi-ticket.png`, `nuvi-fix.png` | Ayuda contextual y errores menores sin impacto financiero |
| `nuvi-sad.png` | No usar en video: el Brand OS no permite llanto ni desesperación |

**Movimiento** (según la guía del personaje): se estira como gel, se comprime, hace loops y rodea objetos. Nunca es brusco: fluido, controlado, eficiente. Su color pasa de azul (normal) a verde (éxito).

Mínimo 120px de alto. Área libre del 12–15 % de su altura. Sin contornos, sombras duras ni recoloreo. Los `.webm` tienen transparencia: en Remotion se reproducen con `<OffthreadVideo transparent>`. El clip "Nuvy Caminando" de Drive viene sobre fondo blanco y necesita una exportación con transparencia.

Los archivos de Drive dicen "Nuvy", pero el nombre oficial es **Nuvi**.
