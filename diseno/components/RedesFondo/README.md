Fondo de todo post de redes: un degradado gris claro en diagonal (`redes-fondo-inicio` → `redes-fondo-fin`) con el isotipo gigante como marca de agua y el wordmark chico arriba al centro.

**Qué provee quien lo usa:** el contenido que va encima. El fondo no lleva texto.

**Reglas:**
- La marca de agua es el isotipo oficial (`assets/Logos/nuvara-isotipo.svg`) usado como máscara de una sola tinta: blanco al 55 % arriba a la derecha y negro al 3.5 % abajo a la izquierda, rotado unos -28°. Nunca a color ni entero dentro del cuadro.
- El wordmark a color mide unos 110px de ancho en un post de 1080, centrado a ~108px del borde superior.
- Para la variante con foto, este fondo se reemplaza por la foto con un velo `redes-azul` a la izquierda.
